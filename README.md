# 마지막 입찰, 사라진 안전기준

조달청 「AI를 활용한 게임 만들기」 공모전 출품작. 10분 안에 서류와 CCTV를 짝지어 입찰 비리를 밝히는 브라우저 추리 게임.

- 플레이: https://sozerong.github.io/last-bid/
- 쉬움 모드: 바탕화면 메신저로 팀장에게 힌트 요청 (2분 간격) / 어려움 모드: 힌트 없음
- 빌드 없음. `index.html`을 열면 바로 실행됩니다.
- CCTV 화면은 이미지 파일 없이 `js/cctv.js`에서 캔버스로 그립니다.
- 폰트: [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1, `fonts/LICENSE.txt`)
